# Font licences

These fonts are served from this site instead of Google Fonts. All three are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/), which allows bundling and redistribution with software.

| Font | Copyright | Source |
|---|---|---|
| Archivo | The Archivo Project Authors | https://github.com/Omnibus-Type/Archivo |
| IBM Plex Sans | IBM Corp. | https://github.com/IBM/plex |
| Martian Mono | The Martian Mono Project Authors | https://github.com/evilmartians/mono |

The `.woff2` files are the Latin and Latin Extended subsets served by Google Fonts. Archivo, IBM Plex Sans (upright) and Martian Mono are variable fonts, so one file covers every weight the site uses.
